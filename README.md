# Bridge Endless Runner

A simple endless runner game built in **Unity** where the player runs across a bridge, dodging obstacles and trying to survive as long as possible.

## Features

* Endless bridge generation
* Obstacles to dodge
* Increasing difficulty
* Score based on distance survived
* Simple player controls

## Built With

* Unity
* C#

## Getting Started

1. Clone the repository.
2. Open the project in Unity Hub.
3. Open the main scene.
4. Press **Play** to start.

## Goal

Survive as long as possible and achieve the highest score.
